# Getting help

| You want to… | Go to |
| --- | --- |
| Get help using the VesselAI platform | Inside the platform, use the **Quick Guide**, ask the built-in **VesselAI Assistant**, or click **Report a problem** |
| Learn how to install or use a repository | That repository's `README.md` |
| Browse the TwinShip ontology | [ontology.twin-ship.eu](https://ontology.twin-ship.eu/) |
| Report a bug or request a feature | The **Issues** tab of the relevant repository |
| Report a security vulnerability | Our [security policy](SECURITY.md); please do not open a public issue |
| Learn about the project, partners and results | [twin-ship.eu](https://twin-ship.eu/) |
| Contact the project team | [info@twin-ship.eu](mailto:info@twin-ship.eu) |

TwinShip is a research and innovation project. We do our best to respond to issues, but we cannot guarantee response times.
