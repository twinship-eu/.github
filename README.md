# twinship-eu/.github

This repository holds organisation-wide settings for the [TwinShip](https://twin-ship.eu/) GitHub organisation.

| Path | Purpose |
| --- | --- |
| [`profile/README.md`](profile/README.md) | Public profile shown on [github.com/twinship-eu](https://github.com/twinship-eu) |
| [`profile/assets/`](profile/assets/) | TwinShip and VesselAI logos (light/dark), the EU flag and the organisation avatar |
| [`profile/assets/vesselai-platform-*.svg`](profile/assets/) | The "platform at a glance" diagram in light and dark versions. These are plain SVG files you can edit directly. |
| [`profile/assets/vesselai-architecture-*.svg`](profile/assets/) | The public architecture diagram in light and dark versions. It omits ports, internal names and versions. |
| [`profile/assets/screens/`](profile/assets/screens/) | VesselAI platform screenshots used on the profile |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | Default contributing guidelines |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Default code of conduct (Contributor Covenant 2.1) |
| [`SECURITY.md`](SECURITY.md) | Default policy for reporting security vulnerabilities |
| [`SUPPORT.md`](SUPPORT.md) | Where to get help |
| [`ISSUE_TEMPLATE/`](ISSUE_TEMPLATE/) | Default issue forms (bug report, feature request) |
| [`PULL_REQUEST_TEMPLATE.md`](PULL_REQUEST_TEMPLATE.md) | Default pull request template |

The community health files above are applied automatically to every repository in the organisation that does not define its own version. See [GitHub's documentation on default community health files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file).

> [!NOTE]
> This repository must stay **public** for the profile README and the default files to take effect.
